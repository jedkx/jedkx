# Original resident

Approved 68×40 RGBA atlas, timings and clip metadata copied from
[jedkx/J-Portfolio](https://github.com/jedkx/J-Portfolio/tree/main/art/resident).

The editable Aseprite source remains in that repository. No source artwork was
changed for this profile. Transparent pupils, the original face ratio and authored
frame durations are retained. Chewing keeps the neutral eye silhouette.

These files are inputs to scripts/render-assets.mjs. Generated SVG paths are
self-contained and keep the same pixel geometry.
